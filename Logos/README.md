# Local team logos

Store transparent PNG files by league and three-letter team abbreviation:

```text
Logos/
  MLB/NYY.png
  NFL/DET.png
  NHL/NYR.png
```

The renderer deliberately places the away logo one-third beyond the left edge and
the home logo one-third beyond the right edge. If a PNG is missing, the display
uses the team's abbreviation so games remain readable.
